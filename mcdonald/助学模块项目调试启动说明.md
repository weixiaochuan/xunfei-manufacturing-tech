# 项目调试启动说明

本文档用于说明别人下载整个 `pomegranate-ai-ppt` 总目录后，如何打开石榴软件并调试当前 AI 助学 MVP。

## 目录结构

下载或解压后，请保持下面的同级目录关系：

```text
pomegranate-ai-ppt/
├─ Pomegranate/          # 石榴软件本体：React + Tauri
├─ learning-assistant/   # AI 助学独立能力目录
├─ ppt-master/           # AI PPT 独立能力目录
└─ 项目调试启动说明.md
```

AI 助学页面默认会查找 `../learning-assistant`，因此 `Pomegranate/` 和 `learning-assistant/` 必须保持同级。

## 环境要求

建议使用 Windows 开发环境。

需要安装：

1. Node.js 18 或更高版本
2. pnpm
3. Rust + Cargo
4. Tauri 所需的 Windows 构建工具

可用命令检查：

```powershell
node -v
npm -v
pnpm -v
cargo -V
rustc -V
```

如果没有 pnpm，可执行：

```powershell
npm install -g pnpm
```

## 安装依赖

进入石榴软件目录：

```powershell
cd Pomegranate
pnpm install
```

## 浏览器调试方式

浏览器调试适合先看前端页面和 AI 助学 MVP 流程。

```powershell
cd Pomegranate
pnpm run dev
```

启动成功后打开：

```text
http://localhost:2010/#/learning-assistant
```

或者先进入首页，再从左侧入口点击 `AI 助学`。

说明：

- 浏览器环境没有 Tauri `invoke` 能力。
- 当前 AI 助学页面已做 fallback：浏览器调试时会使用前端模拟结果，仍然可以完成一次学习计划生成。
- 后续真实数据库、题库、进度记录需要在 Tauri 桌面环境和后端 command 中继续接入。

## 桌面端调试方式

桌面端调试适合验证 Tauri command、Rust service 和本地文件目录检查。

```powershell
cd Pomegranate
pnpm tauri dev
```

如果提示缺少 Windows 编译工具，需要安装 Visual Studio Build Tools，并勾选 C++ 桌面开发相关组件。

如果 `link.exe` 找不到，可以从 Visual Studio Developer PowerShell 启动，或先让系统 PATH 识别 Visual Studio Build Tools。

## AI 助学最小测试流程

进入 `/learning-assistant` 页面后：

1. 保持默认表单内容，或输入自己的学习目标。
2. 点击 `AI 理解目标`。
3. 确认右侧出现目标摘要、当前差距、学习策略、闭环思想。
4. 点击 `生成学习计划`。
5. 确认右侧生成 4 个阶段的学习计划。
6. 检查每个阶段是否包含：
   - 阶段名称
   - 时间安排
   - 阶段目标
   - 学习任务
   - 资源任务
   - 练习任务
   - 检验任务
   - 完成标准
7. 点击 `推荐资源`、`开始测试`、`调整计划`，应出现后续版本接入提示。

## 常见问题

### 打开网页后提示 invoke 报错

请刷新页面并确认当前代码是最新的。AI 助学页面已经在浏览器模式下增加模拟生成逻辑，不应再直接触发 Tauri `invoke`。

### pnpm 找不到

先执行：

```powershell
npm install -g pnpm
```

如果仍找不到，关闭并重新打开终端，让 PATH 生效。

### AI 助学目录检测失败

确认目录关系为：

```text
pomegranate-ai-ppt/
├─ Pomegranate/
└─ learning-assistant/
```

页面里的 `learning-assistant 根目录` 默认值为：

```text
../learning-assistant
```

如果你移动了目录，请在页面中手动填写正确路径。
