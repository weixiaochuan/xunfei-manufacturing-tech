# Pomegranate AI PPT 生成项目使用说明

## 1. 项目简介

本项目基于 Pomegranate 智能笔记软件二次开发，新增了 **AI PPT 生成** 功能。

当前功能包括：

1. 在 Pomegranate 中输入主题、语料、汇报对象、页数、风格等信息。
2. 调用远程 AI 模型理解 PPT 生成需求。
3. 用户确认 AI 整理后的 PPT 生成 Prompt。
4. 调用 ppt-master 生成可编辑 PowerPoint 文件。
5. 支持开发者调试模式，直接导出已有 ppt-master 项目中的 SVG 为 PPTX。

项目特点：

* 输出的是可编辑 PPTX，不是整页截图。
* 支持选择不同 AI 模型。
* 支持选择导出文件夹。
* 支持 ppt-master 高级工作流。
* 普通用户使用“智能生成”，开发者使用“开发者调试”。

## 3. 环境依赖

### 3.1 必需软件

请提前安装：

1. Node.js 22 或较新版本
2. pnpm
3. Rust / Cargo
4. Visual Studio C++ Build Tools
5. Python 3.11
6. Git
7. WPS 或 Microsoft PowerPoint

---

### 3.2 Node.js 与 pnpm

检查：

```powershell
node -v
pnpm -v
```

没有 pnpm 时安装：

```powershell
npm install -g pnpm
```

---

### 3.3 Rust / Cargo

检查：

```powershell
rustc -V
cargo -V
```

没有 Rust 时安装 Rustup：

```text
https://rustup.rs/
```

安装后重新打开终端。

---

### 3.4 Visual Studio C++ Build Tools

Tauri 在 Windows 下需要 MSVC 编译环境。

需要在 Visual Studio Installer 中勾选：

```text
使用 C++ 的桌面开发
Desktop development with C++
```

右侧建议包含：

```text
MSVC x64/x86 生成工具
Windows 10/11 SDK
C++ CMake tools for Windows
```

如普通 PowerShell 里 `cl` 不识别，可以使用 Visual Studio Developer Shell，或执行：

```powershell
& "C:\Program Files\Microsoft Visual Studio\18\Professional\Common7\Tools\Launch-VsDevShell.ps1" -Arch amd64 -HostArch amd64
```

然后测试：

```powershell
cl
```

## 4. 安装 ppt-master 依赖

进入 ppt-master 目录：

```powershell
cd "你的路径\pomegranate-ai-ppt\ppt-master"
```

创建 Python 虚拟环境：

```powershell
py -3.11 -m venv .venv
```

激活虚拟环境：

```powershell
.\.venv\Scripts\Activate.ps1
```

如果 PowerShell 阻止执行脚本，先执行：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

然后重新激活：

```powershell
.\.venv\Scripts\Activate.ps1
```

安装依赖：

```powershell
$env:PYTHONUTF8="1"
python -X utf8 -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

检查依赖：

```powershell
python -X utf8 -m pip check
```

---

## 5. 安装 Pomegranate 主程序依赖

进入 Pomegranate 主程序目录：

```powershell
cd "你的路径\pomegranate-ai-ppt\Pomegranate\Pomegranate"
```

安装前端依赖：

```powershell
pnpm install
```

如果提示 esbuild build scripts 未批准，执行：

```powershell
pnpm approve-builds
pnpm rebuild esbuild
```

构建 MCP sidecar：

```powershell
pnpm build:mcp
```

启动开发模式：

```powershell
pnpm tauri dev
```

## 8. AI 模型配置

AI PPT 需求理解与生成需要配置远程 API 模型。

进入：

```text
设置 → AI 模型
```

添加一个远程模型，例如：

### DeepSeek 示例

```text
Provider：DeepSeek 或 OpenAI Compatible
Base URL：https://api.deepseek.com
Model：deepseek-chat
API Key：填写自己的 API Key
```

### OpenAI-compatible 通用示例

```text
Provider：自定义 OpenAI-compatible
Base URL：你的 API 地址
Model：模型名称
API Key：你的 API Key
```

注意：

1. 不建议默认使用本地 Ollama。
2. 当前项目更适合使用远程 API 模型。
3. 不要把 API Key 写进代码或提交到仓库。
4. 不同任务可以选择不同模型，PPT 生成建议选择文本能力和长上下文能力较好的模型。

## 9. 智能生成 PPT 使用流程

进入：

```text
PPT 生成 → 智能生成
```

按顺序操作：

1. 选择 AI 模型。
2. 输入 PPT 主题。
3. 粘贴原始语料。
4. 选择汇报对象。
5. 选择页数。
6. 选择风格。
7. 填写额外要求。
8. 点击：

```text
理解需求
```

AI 会输出：

```text
AI 理解摘要
重点取舍
叙事主线
建议页面结构
视觉与表达建议
仍需确认的问题
确认用精简 Prompt
```

检查并修改“确认用精简 Prompt”。

然后选择导出文件夹。

最后点击：

```text
确认并生成 PPT
```

成功后会显示：

```text
项目路径 projectPath
设计规范 designSpecPath
页面方案 slidePlanPath
原始 PPTX 路径 pptxPath
最终导出路径 finalPptxPath
```

点击：

```text
打开 PPT
```

即可查看生成结果。

## 11. 常见问题

### 11.1 Vite 报错：The service was stopped

现象：

```text
Pre-transform error: The service was stopped
Plugin: vite:esbuild
```

处理：

```powershell
Get-Process node, esbuild, intelligent_notebook -ErrorAction SilentlyContinue | Stop-Process -Force

Remove-Item -Recurse -Force ".\node_modules\.vite" -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force ".\node_modules\.cache" -ErrorAction SilentlyContinue

pnpm rebuild esbuild
pnpm tauri dev
```

如果仍然失败：

```powershell
pnpm approve-builds
pnpm rebuild esbuild
```

---

### 11.2 Git 提交时报 index.lock

现象：

```text
fatal: Unable to create '.git/index.lock': File exists.
```

处理：

```powershell
Get-Process git -ErrorAction SilentlyContinue
Stop-Process -Name git -Force -ErrorAction SilentlyContinue
Remove-Item ".git\index.lock" -Force -ErrorAction SilentlyContinue
```

然后重新提交。

---

### 11.3 pip 安装 requirements.txt 报 GBK 编码错误

现象：

```text
UnicodeDecodeError: 'gbk' codec can't decode byte
```

处理：

```powershell
$env:PYTHONUTF8="1"
python -X utf8 -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

---

### 11.4 pip 报 ProxyError

现象：

```text
ProxyError('Cannot connect to proxy')
```

处理：

```powershell
Remove-Item Env:HTTP_PROXY -ErrorAction SilentlyContinue
Remove-Item Env:HTTPS_PROXY -ErrorAction SilentlyContinue
Remove-Item Env:ALL_PROXY -ErrorAction SilentlyContinue
Remove-Item Env:http_proxy -ErrorAction SilentlyContinue
Remove-Item Env:https_proxy -ErrorAction SilentlyContinue
Remove-Item Env:all_proxy -ErrorAction SilentlyContinue
```

然后重新安装依赖。

---

### 11.5 AI 理解需求时报 Ollama 连接失败

现象：

```text
无法连接到 Ollama 服务 http://localhost:11434/api/chat
```

原因：

当前选择的 AI 模型是本地 Ollama，但 Ollama 没有启动。

解决方式：

1. 到设置页添加远程 API 模型。
2. 回到 PPT 生成页，选择远程模型。
3. 不使用默认 Ollama。

---

### 11.6 点击生成后没有 PPTX

检查：

1. 是否已经配置 ppt-master 根目录。
2. 是否已经配置 Python 路径。
3. Python 路径是否指向：

```text
ppt-master\.venv\Scripts\python.exe
```

4. 是否选择了可用 AI 模型。
5. 导出文件夹是否存在。
6. 查看页面中的 stdout / stderr / error 信息。

生成项目一般位于：

```text
ppt-master\projects\pome_ppt_xxx
```

最终 PPTX 一般位于：

```text
ppt-master\projects\pome_ppt_xxx\exports
```

如果选择了导出文件夹，最终文件会复制到用户选择的目录。

## 14. 当前版本说明

当前版本已经实现：

1. Pomegranate 调用 ppt-master。
2. AI 需求理解。
3. AI 模型选择。
4. 确认 Prompt。
5. 自动生成 PPTX。
6. 开发者调试导出现有 ppt-master 项目。

1. 本地配置 ppt-master 路径。

5. 增加任务队列和实时生成日志。
