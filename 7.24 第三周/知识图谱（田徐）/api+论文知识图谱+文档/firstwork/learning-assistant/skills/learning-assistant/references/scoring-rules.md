# Scoring Rules

Future versions should use stage scores to decide whether the learner advances
or repeats work.

## Score Bands

- 85 or above: enter the next stage and optionally add advanced tasks.
- 70-84: enter the next stage, but add review tasks for weak knowledge points.
- 60-69: reduce new content in the next stage, add remedial resources and basic practice.
- Below 60: repeat the current stage, lower difficulty, and retest before moving forward.

## MVP Boundary

The MVP does not calculate real scores. It only reserves UI actions for testing,
resource recommendation, progress recording, and plan adjustment.
