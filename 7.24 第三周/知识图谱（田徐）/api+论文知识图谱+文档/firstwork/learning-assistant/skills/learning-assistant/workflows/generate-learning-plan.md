# Generate Learning Plan Workflow

## Purpose

Create an MVP learning plan from user-provided learning information.

## Steps

1. Learning goal input
   - Collect the learning goal, course name, learning cycle, daily study time,
     current foundation, and final target.

2. Goal analysis
   - Summarize the learner's target.
   - Identify the gap between current foundation and final target.
   - Choose a practical learning strategy.
   - Keep the full closed-loop direction visible, even when only the MVP steps are implemented.

3. Stage plan generation
   - Generate 3-5 stages.
   - Allocate each stage to a clear time range.
   - Make stages progressive: framework first, core learning next, practice and output later.

4. Stage task output
   - For every stage, output learning tasks, resource tasks, practice tasks,
     check tasks, and completion criteria.
   - Tasks must be concrete and executable.

## MVP Boundary

The first version does not connect to a real resource database, question bank,
score table, or progress record. Buttons for resource recommendation, testing,
and plan adjustment should show a placeholder notice.
