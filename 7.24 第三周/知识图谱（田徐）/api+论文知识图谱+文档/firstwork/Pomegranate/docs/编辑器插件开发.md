
# 编辑器插件开发指南

## 概述

Tiptap 编辑器已重构为支持插件化的架构，允许开发者开发和集成自定义编辑器实现。

## 核心概念

### EditorCore 接口

所有编辑器实现都需要实现 `EditorCore` 接口：

```typescript
interface EditorCore {
  readonly id: string;
  readonly name: string;
  readonly version: string;
  readonly supportedFileTypes: string[];
  readonly features: string[];

  getContent(): string;
  setContent(content: string): void;
  getSelection(): string;
  replaceSelection(text: string): void;
  insertText(text: string): void;
  focus(): void;
  isReady(): boolean;
  destroy(): void;
}
```

### 编辑器注册表

使用 `EditorRegistry` 管理可用的编辑器：

```typescript
import { editorRegistry } from "@/components/editor";

// 注册编辑器
editorRegistry.register({
  id: "my-editor",
  name: "My Editor",
  supportedFileTypes: ["txt"],
  features: [EDITOR_FEATURES.RICH_TEXT],
  factory: (config) => new MyEditorCore(config),
  defaultConfig: { ... },
});
```

## 创建自定义编辑器

### 1. 实现 EditorCore 类

```typescript
import { EditorCore, EditorConfig } from "@/types/editor";

export class MyEditorCore implements EditorCore {
  readonly id: string;
  readonly name: string = "My Editor";
  readonly version: string = "1.0.0";
  readonly supportedFileTypes: string[] = ["txt"];
  readonly features: string[] = [];

  private instance: any = null;

  constructor(config: EditorConfig = {}) {
    this.id = config.id || `my-editor-${Date.now()}`;
  }

  setEditorInstance(instance: any) {
    this.instance = instance;
  }

  getContent(): string {
    return this.instance?.getContent() || "";
  }

  setContent(content: string): void {
    this.instance?.setContent(content);
  }

  // ... 其他方法实现
}
```

### 2. 创建 React 组件

```typescript
import React, { useEffect, useRef } from "react";
import { MyEditorCore } from "./MyEditorCore";
import { EditorProvider, useEditor } from "@/components/editor";

function MyEditorWrapper(props: any) {
  const { setContent } = useEditor();
  const editorRef = useRef<any>(null);

  // 实现组件逻辑
  return <div>...</div>;
}

export function MyEditor(props: any) {
  const editorCoreRef = useRef<MyEditorCore | null>(null);

  if (!editorCoreRef.current) {
    editorCoreRef.current = new MyEditorCore({
      initialContent: props.content,
    });
  }

  return (
    <EditorProvider
      editor={editorCoreRef.current}
      noteId={props.noteId}
      initialContent={props.content}
      onContentChange={props.onChange}
    >
      <MyEditorWrapper {...props} />
    </EditorProvider>
  );
}
```

## 创建编辑器扩展

### EditorExtension 接口

```typescript
interface EditorExtension {
  id: string;
  name: string;

  onInit?: (context: EditorContext) => void;
  onContentChange?: (content: string, context: EditorContext) => void;
  onSelectionChange?: (selection: string, context: EditorContext) => void;
  onFocus?: (context: EditorContext) => void;
  onBlur?: (context: EditorContext) => void;
  onDestroy?: (context: EditorContext) => void;

  toolbarButtons?: ToolbarButton[];
  contextMenuItems?: ContextMenuItem[];
  shortcuts?: KeyboardShortcut[];
}
```

### 注册扩展

```typescript
import { useEditorExtension } from "@/components/editor";

const myExtension: EditorExtension = {
  id: "my-extension",
  name: "My Extension",

  onInit: (context) => {
    console.log("Extension initialized");
  },

  toolbarButtons: [
    {
      id: "my-button",
      icon: "star",
      label: "My Button",
      onClick: (context) => {
        // 处理点击
      },
    },
  ],
};

// 在组件中使用
function MyComponent() {
  useEditorExtension(myExtension);
  return <div>...</div>;
}
```

## 迁移指南

### 从旧架构迁移到新架构

1. **保持现有代码不变**：现有 `TiptapEditor` 组件继续正常工作
2. **逐步采用新功能**：新功能可以使用 `UnifiedEditor` 和新的扩展系统
3. **注册自定义编辑器**：根据需要注册自定义编辑器实现

### 代码示例

```typescript
// 旧代码（继续工作）
import { TiptapEditor } from "@/components/editor";

// 新代码
import { UnifiedEditor, EditorRegistryEntry } from "@/components/editor";

// 注册自定义编辑器
const MyEditorEntry: EditorRegistryEntry = {
  id: "my-editor",
  name: "My Editor",
  supportedFileTypes: ["custom"],
  features: [EDITOR_FEATURES.RICH_TEXT],
  factory: (config) => new MyEditorCore(config),
};

editorRegistry.register(MyEditorEntry);

// 使用新编辑器
<UnifiedEditor content={content} onChange={onChange} editorId="my-editor" />
```

## 最佳实践

1. **保持向后兼容**：先保留现有代码，逐步迁移
2. **使用功能特性**：根据支持的功能特性注册编辑器
3. **错误处理**：编辑器实现应该有适当的错误处理
4. **性能优化**：避免频繁的内容更新，使用防抖
5. **文档完整**：为自定义编辑器和扩展提供完整文档
