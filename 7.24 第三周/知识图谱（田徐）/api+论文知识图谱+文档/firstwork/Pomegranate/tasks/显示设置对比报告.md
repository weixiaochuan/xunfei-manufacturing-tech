# 显示设置对比报告：KnowledgeBase vs Intelligent Notebook

## 1. 数据结构对比

### 外观自定义

| 设置项 | KnowledgeBase | Intelligent Notebook 当前 | 差距 |
|--------|:---:|:---:|------|
| 启用自定义开关 | ✅ Switch (`themeOverridesEnabled`) | ❌ 无 | **缺失** |
| 强调色 | ✅ ColorPicker + 8 色快速色板 (`customAccent`) | ❌ 无 | **缺失** |
| 背景图 | ✅ 选择/更换/清除 (`customBgImage`) | ❌ 无 | **缺失** |
| 背景遮罩 | ✅ Slider 0-100% (`customBgDim`) | ❌ 无 | **缺失** |
| 背景适配 | ✅ Select 覆盖/包含/原始/平铺 (`customBgFit`) | ❌ 无 | **缺失** |
| 背景模糊 | ✅ Slider 0-30px (`customBgBlur`) | ❌ 无 | **缺失** |
| 亮色/暗色切换 | AppLayout 菜单 (`themeCategory`) | ✅ 自定义 Radio.Group | 各有 |
| 主题预设 4 套 | AppLayout 菜单 (`lightTheme/darkTheme`) | ✅ 4 张卡片 | 各有 |

### 编辑器外观

| 设置项 | KnowledgeBase | Intelligent Notebook 当前 | 差距 |
|--------|:---:|:---:|------|
| 正文字体 | ✅ Select | ✅ Select | 一致 |
| 正文字号 | ✅ Select | ✅ Select | 一致 |
| 行距 | ✅ Select | ✅ Select | 一致 |
| 阅读列宽 | ✅ Select (`editorReadingWidth`) | ❌ 无 | **缺失** |
| 纸张观感 | ✅ Switch (`editorPaper`) | ❌ 无 | **缺失** |
| 背景纹理 | ✅ Radio 无/横线/网格 (`editorRuleLines`) | ❌ 无 | **缺失** |
| 首行缩进 | ✅ Switch (`editorFirstLineIndent`) | ❌ 无 | **缺失** |
| 高亮快捷键 | ✅ `EditorHighlightShortcutRow` | ❌ 无 | **缺失** |
| 预览 | ✅ 文字预览 + 恢复默认 | ✅ 文字预览 + 恢复默认 | 一致 |

## 2. 架构依赖分析

### 前置依赖（Intelligent Notebook 缺失，需要补齐）

```
┌─ Store (src/store/index.ts)
│   ├── themeOverridesEnabled  : boolean
│   ├── customAccent           : string | null
│   ├── customBgImage          : string | null
│   ├── customBgDim            : number (0-1)
│   ├── customBgBlur           : number (0-30)
│   ├── customBgFit            : "cover"|"contain"|"center"|"repeat"
│   ├── editorReadingWidth     : number
│   ├── editorPaper            : boolean
│   ├── editorRuleLines        : EditorRuleLines
│   ├── editorFirstLineIndent  : boolean
│   └── EDITOR_READING_WIDTH_OPTIONS/LABELS
│       EDITOR_RULE_LABELS
│       EditorRuleLines type
│
├─ Rust Command (src-tauri/src/commands/)
│   ├── copy_theme_bg          : 复制背景图到数据目录
│   └── clear_theme_bg         : 清除背景图
│       （KB 中 invoke("copy_theme_bg") / invoke("clear_theme_bg")）
│
├─ CSS/Theme System
│   ├── --kb-accent 变量注入（强调色覆盖 antd colorPrimary）
│   ├── 背景图层 + backdrop-filter blur
│   ├── 编辑器纸张观感（白卡 + 阴影）
│   └── 编辑器纹理底纹（横线/网格 CSS background）
│
└─ Components
    └── EditorHighlightShortcutRow（编辑器高亮快捷键配置行）
```

### 渐变风险

| 风险项 | 级别 | 说明 |
|--------|------|------|
| Store 属性扩展 | 🟡 中 | 新增 ~10 个 store 属性，需同步持久化到 tauri-plugin-store |
| Rust Command 新增 | 🟡 中 | 需要 `copy_theme_bg` 和 `clear_theme_bg` 两个命令 |
| CSS 系统改造 | 🔴 高 | 强调色注入、背景图层、编辑器纹理均需全局 CSS 配合 |
| 编辑器纹理渲染 | 🔴 高 | `editorRuleLines` 需 Tiptap editor 支持，可能需扩展 Tiptap 插件 |

## 3. 实施策略

### 方案 A：完整迁移（高成本）

**做法**：将 KnowledgeBase 的所有外观功能全部迁移到 Intelligent Notebook，包括 Store、Rust Commands、CSS、编辑器插件。

**工作量**：3-5 天
**风险**：高

### 方案 B：渐进迁移（推荐）

**做法**：分两期实施。

**Phase 1（本次）**：外观自定义 + 扩展编辑器外观（不含后端/CSS 改造）
- Store 新增全部属性
- 设置页 UI 完整迁移（`外观自定义` 和 `编辑器外观` 两个 Card）
- `copy_theme_bg` / `clear_theme_bg` 暂时作为占位（调用失败不崩溃）
- 编辑器纹理/纸张观感/首行缩进开关可见但灰度说明"即将上线"

**Phase 2（后续）**：
- Rust 侧补齐 `copy_theme_bg` / `clear_theme_bg` Commands
- CSS 系统改造（强调色注入、背景图、纹理）
- Tiptap 编辑器插件适配（纸张观感、纹理、首行缩进）
