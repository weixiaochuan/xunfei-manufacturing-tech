# 设置页竖直 Tabs 重组方案

## Context

当前设置页 `src/pages/settings/index.tsx` 采用"左侧锚点 + 右侧长页面"模式，设置项已经过多，查找成本高。目标是改为左侧竖直 Tabs，并按用户指定的 6 个一级分类组织内容。同时，"关于"不再使用设置页原来的简化作者社区卡片，而是复用侧边栏关于按钮对应的 `/about` 页面核心内容：系统信息、数据迁移说明、作者 & 社区。

仓库当前有大量未提交改动，且涉及本次关键文件（`src/pages/settings/index.tsx`、`src/pages/about/index.tsx`、`src/styles/global.css` 等）。实施时只改本需求相关文件，不做全文件格式化，不覆盖无关改动。

---

## 推荐方案

### 1. 抽取可复用 About 内容组件

修改/新增：
- `src/pages/about/index.tsx`
- `src/components/about/AboutContent.tsx`（新增）

从 `src/pages/about/index.tsx` 抽出核心内容组件 `AboutContent`，供 About 页面和设置页 About Tab 共用。

组件能力：
- 自行加载 `systemApi.getSystemInfo()`
- 自行处理 `openPath(info.dataDir)`、`openUrl()`、`updaterApi.checkUpdate()`、`UpdateModal`
- 支持 props 控制显示内容：
  - `showHeader` — 标题区"关于"
  - `showNavigateToSettings` — "前往设置"按钮
  - `showSponsor` — 赞赏支持
  - `showRecommend` — 推荐应用
  - `idPrefix` — 锚点 id 前缀

使用方式：
- `/about` 页面：全部 true，完整展示
- 设置页"关于"Tab：只显示系统信息、数据迁移说明、作者 & 社区（不显示赞赏支持、推荐应用）

### 2. 设置页改为 Ant Design 竖直 Tabs

修改：
- `src/pages/settings/index.tsx`
- `src/styles/global.css`

将 `DesktopSettingsPage` 从"锚点滚动布局"改为：
- 页面标题
- `<Tabs tabPosition="left" />`
- 每个 Tab 内用纵向 stack 展示现有 Card / Section

初版不启用销毁 inactive Tab（`destroyInactiveTabPane={false}`），避免 AI 模型、导入导出、模板弹窗、同步状态在切换 Tab 时丢失。

### 3. 严格按 6 个一级分类放置设置项

#### Tab 1 — AI模型

| 内容 | 来源 |
|------|------|
| AI Provider 注册状态 | `settings-ai-provider` |
| AI 模型配置 | `settings-ai-models` |
| 语音识别 | `AsrSection` |
| MCP 服务 | `MCPServerSection` |

#### Tab 2 — 应用配置

| 内容 | 来源 |
|------|------|
| 数据目录 | `DataDirSection` |
| 日记文件存储路径 | `settings-daily-md-path` |
| 孤儿素材清理 | `OrphanAssetsPanel` |
| 自动保存 | 新增轻量说明卡片：基于现有 `useAutoSave` 事实说明已有自动保存；若现有无全局开关，第一版不新增后端能力 |
| 导入笔记 | `settings-import` |
| 导出 Markdown | `settings-export` |
| 数据同步与备份 | `SyncTabs` |
| 插件设置 | `pluginSettingsTabs`（非空时归入末尾，保留原 id） |

#### Tab 3 — 个性设置

| 内容 | 来源 |
|------|------|
| 待办提醒 | `settings-task-reminder` |
| 笔记模板 | `settings-templates` |
| 隐藏笔记访问保护 | `HiddenPinSection` |
| 全局快捷键 | `ShortcutsSection`（用户未列出但已有入口，保留在个性设置末尾） |

#### Tab 4 — 显示设置

| 内容 | 来源 |
|------|------|
| 外观定义 | 新增：复用 `useAppStore` 中 `themeCategory`/`lightTheme`/`darkTheme` 等，做主题选择卡片 |
| 编辑器外观 | `settings-editor` |

#### Tab 5 — 更新启动

| 内容 | 来源 |
|------|------|
| 软件更新 | `settings-update` |
| 启动设置 | `settings-startup` |
| 侧边栏 | `FeatureModulesSection`（给它加可选 props 显示标题"侧边栏"） |

#### Tab 6 — 关于

> 使用 `AboutContent` 组件，只显示核心内容。

| 内容 | 来源 |
|------|------|
| 系统信息 | `about-system` |
| 数据迁移说明 | `about-migration` |
| 作者 & 社区 | `about-community` |

移除设置页原有：
- `settings-community` 简化作者社区 Card
- 设置页底部 `RecommendCards`

### 4. 保持弹窗和状态在 `DesktopSettingsPage` 顶层

以下弹窗继续放在 `DesktopSettingsPage` return 末尾，不下沉到 Tab 组件内部：
- 导入预览 `Modal`
- AI 模型添加/编辑 `Modal`
- 模板编辑 `Modal`
- 软件更新 `UpdateModal`

这样可避免切换 Tab 导致弹窗状态丢失。

### 5. 兼容旧跳转锚点

现有设置页会读取 `location.state.scrollTo` 并 `scrollIntoView()`。改 Tabs 后新增 `sectionId -> tabKey` 映射：

| 旧 sectionId | 新 Tab |
|-------------|--------|
| `settings-ai-provider`, `settings-ai-models`, `settings-asr`, `settings-mcp` | AI模型 |
| `settings-daily-md-path`, `settings-data-dir`, `settings-orphan-assets`, `settings-import`, `settings-export`, `settings-sync`, `settings-plugin-*` | 应用配置 |
| `settings-task-reminder`, `settings-templates`, `settings-hidden-pin`, `settings-shortcuts` | 个性设置 |
| `settings-appearance`, `settings-editor` | 显示设置 |
| `settings-update`, `settings-startup`, `settings-features` | 更新启动 |
| `settings-about-system`, `settings-about-migration`, `settings-about-community`, `settings-community` | 关于 |

处理流程：
1. 读取 `location.state.scrollTo`
2. 切换对应 Tab
3. 下一帧 `scrollIntoView()`
4. 保留 `settings-target-flash` 高亮效果

### 6. 样式

在 `src/styles/global.css` 增加局部样式：
- `.settings-tabs-page` — 设置页整体容器
- `.settings-tabs-shell` — 左侧 Tab + 右侧内容区外层
- `.settings-tabs-stack` — 右侧内容纵向排列

目标：左侧 Tab 宽度稳定、右侧内容垂直排列 Card 间距 16px、内容区可滚动。移动端仍走 `MobileMe`。

## 关键文件

| 文件 | 动作 |
|------|------|
| `src/pages/settings/index.tsx` | 重写为 Tabs 容器 |
| `src/pages/about/index.tsx` | 抽取 `AboutContent` 组件 |
| `src/components/about/AboutContent.tsx` | 新增：可复用关于内容 |
| `src/components/settings/FeatureModulesSection.tsx` | 增加可选 props |
| `src/styles/global.css` | 增加设置页 Tabs 样式 |

## 不在本次做的事

- 不改 Rust 后端接口
- 不新增数据库表或迁移
- 不删除 `/about` 路由
- 不改移动端 `MobileMe` 结构
- 不大规模拆分 `settings/index.tsx` 为多个业务组件文件

## 验证计划

1. `npx tsc --noEmit` 检查 TypeScript
2. 打开 `/settings`，确认 6 个竖直 Tab 顺序正确
3. 检查每个 Tab 内容完整
4. 确认设置页不再出现原简化 `settings-community` 和 `RecommendCards`
5. 打开 `/about`，确认原关于页仍可访问且内容不缺失
6. 测试软件更新按钮、AI 模型弹窗、导入预览弹窗、模板弹窗均正常
7. 测试 `location.state.scrollTo` 跳转到正确 Tab 并滚动
