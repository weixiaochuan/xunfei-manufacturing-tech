# 小白指南 · v20（最终版）

## 这一轮加了三样东西

### ⭐ 1. RAG 检索（你说优先做的，做完了）

**以前的问题**：出题时只把**这一个知识点**喂给模型 → 模型只能"复述教材"，出不了有深度的题。

**现在**：出题前先检索，把三样东西一起塞进 Prompt：
- **相关知识点** → 能出**跨知识点**的题
- **真题范例** ⭐ → 让模型学**真题的出题手法**，而不是复述教材
- **学生的常见误区** → 直接做干扰项

**真实效果**（出第二章「工艺尺寸链」的题时，检索召回了这些）：
```
【相关知识点】
· 装配尺寸链与工艺尺寸链的区别（第六章）   ← 跨章节召回！
· 直线尺寸链的极值法计算公式（第二章）：A₀=∑增−∑减; T₀=∑Tᵢ
· 装配尺寸链的概念与构成（第六章）

【范例题】⭐ 学它的出题手法
· [真题·名词解释·4分] 尺寸链
· [教材习题·单选·2分] （判断）直线尺寸链中必须有增环和减环。

【学生的常见误区】（做干扰项）
· 混淆了两种尺寸链的封闭环定义...
```

**看出来了吗**：出的是**第二章**的题，但把**第六章**的装配尺寸链也召回来了。
**模型现在能出「对比工艺尺寸链和装配尺寸链」这种题了** —— 以前它根本看不到第六章的内容。

**RAG 防幻觉**（比赛大纲第 5 页明确要求的）：
出完题反查知识库——教材里找不到依据的，标记出来让人看一眼。
实测：真实概念相似度 0.217（通过）；我编的"区块链哈希共识"相似度 0.072（被标记）。

> **RAG 是增强，不是依赖**：索引挂了、检索失败了，出题**照常进行**（退回老模式），不会崩。

### 2. 错题本（`📕 我的错题本` 按钮）

学生做错的题按知识点归堆。**最有价值的不是"我错了几道"，而是"我哪个概念反复错"。**
重做对了会**自动移出**错题本。

### 3. 面试文档更新了

原来写的是"RAG 是下一步要做的"——**现在做完了，改了口**。
还新增了一道题：**「你们的 RAG 用的什么向量库？」** 这题是坑，我给了标准答法。
