# 图片资源目录

- 图片文件放在 `assets/images/ch<章号>/` 下，文件名用英文+数字，不要用中文。
- 数据库里只存**相对路径**（如 `assets/images/ch3/v_block_01.png`），不存图片本身。
- 答题服务器会把 `/assets/...` 暴露为静态资源，网页直接 `<img src="/assets/...">` 引用。
- 将来要上线，把路径换成对象存储 URL 即可，代码不用改。

## 图从哪来
1. 教材/真题原图（最准，首选）
2. 用代码按题目参数画图（尺寸链、公差带、V形块受力等规则图形；准确性有保证）
3. AI 文生图 —— **工程图不要用**，尺寸和投影关系会错。
