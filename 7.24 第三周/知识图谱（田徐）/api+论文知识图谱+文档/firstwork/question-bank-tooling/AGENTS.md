# AGENTS.md —— 给 AI 编程助手（Codex / Claude Code / Cursor）的说明

## 项目是什么

大学课程《机械制造工艺学》的智能题库系统（学-练-考）。
- 技术栈：Python 3（标准库 + sqlite3）+ 原生 HTML/CSS/JS（**无前端框架**）
- 所有数据在 `db/question_bank.db` 这**一个 SQLite 文件**里
- 模型调用：DeepSeek API（可选，不填 `--provider` 就是离线模式）

## ⚠️ 硬性约束（违反 = 严重 bug）

### 1. 题目列表接口绝对不能返回答案

`GET /api/questions`（在 `demo/serve_quiz.py`）**不能返回**这些字段：
- `answer`（标准答案）
- `explanation`（解析）
- `answer_image_path` / `answer_image`（答案图）
- `options_json` 里的 `is_correct`（哪个选项是对的）

**原因**：这个接口的返回会直接进浏览器，**学生按 F12 就能看到答案**。这是泄题。

**答案只能从 `POST /api/answer` 返回**（也就是学生提交之后）。

> 这个 bug 真实发生过。如果你觉得"前端拿不到答案不方便"，**那是对的，就是要不方便。**

### 2. 没有标准答案的题，不能给学生

筛选"能给学生做的题"，**必须同时满足两个条件**：
```sql
WHERE review_status = '已通过'
  AND COALESCE(usage_scope, '学生练习') = '学生练习'
```
- `usage_scope = '教师出题'` 的题（35 道）**没有标准答案**，只给老师出题参考。
  给学生做的话，反馈会是错的。**错的反馈比没有反馈更糟。**
- `review_status != '已通过'` 的题没过审核。

### 3. student_id 必须从请求里取，不能写死

所有涉及学生数据的接口（`/api/answer`、`/api/recommend`、`/api/progress`），
**必须用请求里传的 `student_id`**（见 `Handler._student()` 方法）。

**不能写死 `demo_student`**，否则所有学生的数据会混在一起
（张三做的题算到李四头上，掌握度、推题全乱）。

> 这个 bug 也真实发生过。

### 4. 绝对不许编造答案

如果一道题没有标准答案，**就不要给它编一个**。
宁可把它标成 `usage_scope='教师出题'` 排除掉，也不能让模型瞎编一个答案给学生。

### 5. "原卷截图题"（question_id 以 `P_` 开头）的特殊处理

这类题（7 道计算题）的：
- `stem`（文字题干）**是残缺的**（PDF 提取会把上标下标打散）
- 完整题目在 `image_path` 那张图里
- **标准答案在 `answer_image_path` 那张图里**（含尺寸链、公式、采分点）

**题干图和答案图必须分开**。不能合成一张贴在题干下面
（否则学生还没提交就看到答案了）。

## 关于 RAG（v20 新增）

出题时会先调 `pipeline/rag.py` 检索：相关知识点 + 真题范例 + 常见误区，
拼成一段上下文塞进 Prompt。**这是为了让模型能出跨知识点的题、学真题的出题风格。**

- **RAG 是增强，不是依赖**：索引不存在或检索失败时，`build_rag_block()` 返回空字符串，
  出题**照常进行**（退回单知识点模式）。**不要改成"检索失败就报错"。**
- **改了题库之后要重建索引**：`python pipeline/rag.py --build`（几秒钟，不联网不花钱）
- **想换成真向量模型**（BGE/OpenAI）：只需要实现 `embed(texts) -> vectors`，
  替换 `rag.py` 里的 `TfidfVectorizer`。其它代码（出题、Prompt 拼装）**完全不用改**。
  接口注释里标了 `EMBEDDING_ADAPTER`。

## 改完之后必须做的

```bash
python pipeline/check_web.py
```
**必须全绿。** 这个脚本会检查：
- 页面能不能打开（JS 有没有语法错、变量有没有声明）
- 所有接口通不通
- **有没有把没答案的题泄漏给学生**

## 目录速查

| 路径 | 是什么 |
|---|---|
| `db/question_bank.db` | **唯一数据源**（题目、知识点、作答记录、掌握度） |
| `demo/serve_quiz.py` | HTTP 服务，所有 API |

| `pipeline/check_web.py` | 发布前自检 |
| `prompts/` | 所有 Prompt 模板 |
| `INTERFACE_对接文档.md` | 完整的 API 文档 |

## 数据字典

- **题型（5种）**：`单选` `多选` `名词解释` `简述` `计算`
- **来源（3种）**：`真题` `教材习题` `AI生成`
- **使用范围**：`学生练习` / `教师出题`
- **Bloom**：`记忆` `理解` `应用` `分析`
- **章节（7个，名字必须完全一致）**：
  `第一章_绪论` `第二章_机械加工工艺规程设计` `第三章_机床夹具设计`
  `第四章_机械加工精度及其控制` `第五章_机械加工表面质量及其控制`
  `第六章_机器装配工艺过程设计` `第七章_机械制造工艺理论和技术的发展`

## 多选题的判分规则（老师定的，不要改）

- 全部答对 → 满分
- 答对一部分，**且没有选错的** → 一半分
- **但凡选错一个 → 0 分**
