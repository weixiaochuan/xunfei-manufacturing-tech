# Planning Rules

## Stage Count

Generate 3-5 stages.

## Required Fields Per Stage

Every stage must include:

- Stage name.
- Time arrangement.
- Stage goal.
- Learning tasks.
- Resource tasks.
- Practice tasks.
- Check tasks.
- Completion criteria.

## Task Quality

Tasks must be specific and executable. Avoid vague items such as only:

- Review.
- Study.
- Practice.
- Read materials.

Prefer concrete actions such as:

- Read chapter 1 and write a 10-line concept map.
- Complete 20 basic exercises and classify mistakes.
- Explain one core concept without notes.
- Finish one small project and compare it against the target checklist.

## Resources

The MVP may use simulated resources or generic resource tasks.

The formal version must fetch resources from the application database or a
validated resource index, then attach resource IDs or source metadata to the
plan.
