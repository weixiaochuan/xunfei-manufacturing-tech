## 一、后端：新增 GitInfo + get_git_info Command

### 1.1 数据模型 (`src-tauri/src/models/mod.rs`)

- [ ] 在 `SystemInfo` 下方新增 `GitInfo` 结构体
  ```rust
  #[derive(Debug, Clone, Default, Serialize)]
  #[serde(rename_all = "camelCase")]
  pub struct GitInfo {
      pub branch: Option<String>,
      pub is_clean: bool,
      pub changed: i32,
      pub staged: i32,
      pub untracked: i32,
      pub ahead: i32,
      pub behind: i32,
  }
  ```

### 1.2 Command (`src-tauri/src/commands/system.rs`)

- [ ] 添加 `use std::process::Command;`
- [ ] 实现 `get_git_info()` — 调 `git branch --show-current` + `git status --porcelain` + `git rev-list --count --left-right @{upstream}...HEAD`
- [ ] Windows 设 `CREATE_NO_WINDOW` 避免弹出 CMD 窗口
- [ ] 容错：非 git 仓库返回 `GitInfo::default()`

### 1.3 注册 (`src-tauri/src/lib.rs`)

- [ ] `generate_handler![]` 中追加 `commands::system::get_git_info`
