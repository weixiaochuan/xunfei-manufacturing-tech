# 插件功能 第二阶段 — UI 扩展点详尽版

> **前置**：阶段 1（运行时 + AppAPI 1.0.0）已完成（commit `bc89f0e`）。
> **方向**：纯运行时 UI 注入（manifest 不再用于 UI 贡献），目标对标 Obsidian 可用度。
> **范围**：命令面板 / 侧栏视图 / 功能区 / 编辑器扩展点 / 设置面板 / 错误隔离 / 热重载。

---

## 0. 设计原则（贯穿全阶段）

1. **manifest 仅声明元数据 + 权限**，不再声明 `contributes.commands` / `sidebarViews`。所有 UI 贡献由插件 `onLoad` 时调用 `app.*.add*()` 注入。
2. **注册表是唯一真相源**：`PluginManager.registry.{commands,sidebar,panelViews,ribbon,editorMenus,settingsTabs}` 6 张 Map。
3. **Set 订阅模型**：所有 UI 消费方通过 `pluginManager.subscribe(event, refresh)` 拉取（已在阶段 1 验证可靠）。
4. **错误隔离**：任何插件 API 调用、render、callback 抛错都 try-catch，message.error 给用户提示，但不污染其他插件 / 主应用。
5. **跨平台无差异**：所有 UI 注入走 React 受控渲染，不用 iframe / Web Components。
6. **三层架构不变**：新增前端能力主要在 `src/services/pluginManager.ts` + `src/services/pluginApi.ts`；后端仅在涉及新权限/Capabilities 时动。

## 2. AppAPI 1.1.0 增量设计

阶段 1 是 AppAPI 1.0.0；阶段 2 升级到 **1.1.0**（向后兼容，仅新增）。

### 2.1 新增域

```ts
interface PluginAppAPI {
  readonly version: "1.1.0";
  // ... 1.0.0 已有：workspace, notes, settings, notices, commands, sidebar, panelViews, events

  // ★ 1.1.0 新增：
  ribbon: PluginRibbonAPI;          // 功能区图标
  editor: PluginEditorAPI;          // 编辑器扩展
  settings: PluginSettingsAPI;      // 现有 settings 子 API 扩展 registerTab/createForm
}
```

### 2.2 详细接口

```ts
// ─── ribbon 域 ─────────────────────────
interface PluginRibbonItemDef {
  id: string;
  icon: string;               // Lucide 图标名
  tooltip: string;
  onClick: () => void | Promise<void>;
}
interface PluginRibbonAPI {
  addItem(def: PluginRibbonItemDef): void;
  removeItem(id: string): void;
}

// ─── editor 域 ─────────────────────────
interface PluginEditorContextMenuItemDef {
  id: string;
  label: string;
  icon?: string;
  /** 何时显示：always / has-selection / cursor */
  when?: "always" | "has-selection" | "cursor";
  callback: (ctx: EditorActionCtx) => void | Promise<void>;
}
interface PluginEditorToolbarButtonDef {
  id: string;
  icon: string;
  tooltip: string;
  callback: (ctx: EditorActionCtx) => void | Promise<void>;
}
interface EditorActionCtx {
  noteId: number;
  selection: string;
  cursorPos: number;
  /** 操作 API（受控，不暴露 Tiptap editor 实例） */
  replaceSelection(text: string): void;
  insertText(text: string): void;
  getContent(): string;
  setContent(md: string): void;
}
interface PluginEditorAPI {
  addContextMenuItem(def: PluginEditorContextMenuItemDef): void;
  addToolbarButton(def: PluginEditorToolbarButtonDef): void;
  removeContextMenuItem(id: string): void;
  removeToolbarButton(id: string): void;
  /** 主动查询当前选区（非 ctx 模式时用） */
  getCurrentSelection(): string | null;
}

// ─── settings 域扩展 ────────────────────
interface PluginSettingsTabDef {
  id: string;
  title: string;
  /** 返回 cleanup 函数 */
  render: (container: HTMLElement) => void | (() => void);
}
interface PluginSettingsFormSchema {
  fields: Array<
    | { kind: "text"; key: string; label: string; default?: string; placeholder?: string }
    | { kind: "number"; key: string; label: string; default?: number; min?: number; max?: number }
    | { kind: "boolean"; key: string; label: string; default?: boolean }
    | { kind: "select"; key: string; label: string; options: Array<{ value: string; label: string }>; default?: string }
  >;
}
interface PluginSettingsAPI {
  // 1.0.0 已有：get / set / getAll

  // 1.1.0 新增：
  registerTab(def: PluginSettingsTabDef): void;
  unregisterTab(id: string): void;
  /** 工具函数：基于 schema 自动生成 antd Form，自动 get/set 到 settings */
  createForm(container: HTMLElement, schema: PluginSettingsFormSchema): () => void;
}
```

### 2.3 PluginManager 新增注册表

```ts
private registry = {
  // 1.0.0 已有：
  commands: new Map<string, ...>(),
  sidebar: new Map<string, ...>(),
  panelViews: new Map<string, ...>(),

  // 1.1.0 新增：
  ribbon: new Map<string, PluginRibbonItemDef & { pluginId: string }>(),
  editorContextMenus: new Map<string, PluginEditorContextMenuItemDef & { pluginId: string }>(),
  editorToolbar: new Map<string, PluginEditorToolbarButtonDef & { pluginId: string }>(),
  settingsTabs: new Map<string, PluginSettingsTabDef & { pluginId: string }>(),
};

// 订阅事件相应新增：
type RegistryEvent =
  | "commands" | "sidebar" | "views"     // 1.0.0
  | "ribbon" | "editor-menus" | "editor-toolbar" | "settings-tabs";  // 1.1.0
```

`cleanupPluginRegistry(pluginId)` 同步清理所有 6+ Map，按前缀 `${pluginId}:` 删除并 emit 所有相关事件 — 这套机制阶段 1 已验证，新增的注册表照搬即可。

## 11. 与远端被覆盖的版本（b0e6ad2）的差异说明

远端 v1.8.2 的"插件第一阶段"走的是 **manifest 静态贡献**路线（`contributes.sidebarViews` 在 plugin.json 中预声明）。本阶段确认废弃这条路线，原因：

1. 静态贡献无法描述动态行为（按条件显示、运行时配置）
2. 与运行时 `app.sidebar.addItem` 并存会让插件作者迷惑
3. Obsidian / VS Code 都走运行时注入

如未来确实需要"预渲染图标"（首屏快速显示），再考虑在 manifest 加 `contributes.preload.sidebarIcons`，作为运行时 API 的优化提示，**不作为真相源**。
