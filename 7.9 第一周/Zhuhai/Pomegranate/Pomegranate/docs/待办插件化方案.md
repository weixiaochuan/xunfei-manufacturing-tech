### 2.2 改造为插件的核心矛盾

| 维度 | 耦合度 | 插件化阻力 |
|---|---|---|
| `tasks` 表 17 字段 + 7 次迁移 + 9 索引 + 跨表外键 | 🔴 | 🔴 极高 |
| `task_links` 笔记 ↔ 任务关联 | 🟡 | 🟡 中 |
| 提醒调度器（常驻进程） | 🔴 | 🔴 高（PluginAppAPI 无 worker 概念） |
| AI 批量规划（产品差异化） | 🔴 | 🔴 极高 |
| 侧边栏 TasksPanel + 全局快捷键 | 🟢 | 🟢 低 |
| MobileHome 仪表盘任务卡 | 🟡 | 🟡 中 |
| god node `taskApi`（18+ 调用方） | 🔴 | 🔴 极高 |

**关键洞察**：
- `tasks` 表**不是叶子表** — 与 `task_links`、`task_categories`、`tasks.parent_task_id` 形成 4 表 schema 簇
- AI 是任务系统的**杀手级特性** — `PlanFromGoal/PlanToday` 通过 LLM 输出任务草稿后批量入库
- 提醒调度器是**常驻 worker** — 不像 PIN 是 UX 门禁，错过提醒就丢失功能价值
- god node 强度与 ASR `MicButton`、隐藏笔记 `useAppStore` 同级

## 三、方案对比

### 🅰️ 全插件化 — ❌ 不可行

| 项目 | 说明 |
|---|---|
| 做什么 | 把 `tasks` 表 + 提醒调度器 + 38 个 Command + 13 个前端文件**全部搬到插件** |
| 致命问题 1 | AI 规划功能直接断裂（PlanFromGoal 瘫痪） |
| 致命问题 2 | 18+ 跨模块调用全要改为"先检查插件是否启用 → 再调用 app.tasks.* → 没启用就降级" |
| 致命问题 3 | task_links 跨表外键悬空（笔记的"关联任务"按钮失效） |
| 致命问题 4 | MobileHome 仪表盘失去"今日待办"卡片 |
| 致命问题 5 | 用户禁用插件 = 失去产品差异化能力 |
| 结论 | 🔴 **不可行** |

### 🅱️ 半插件化 — ⚠️ ROI 极差

| 项目 | 说明 |
|---|---|
| 做什么 | Rust 留 schema + 38 Command，前端 `/tasks` 页和 TasksPanel 抽到插件 |
| 工作量 | 🔴 巨大（2-3 天）：38 个 `plugin_proxy_tasks_*` 代理 ≈ 600 行 + 抽 ~2700 行 UI |
| 删除收益 | 仅 ~1450 行 |
| 残留耦合 | AI 模块、首页、笔记编辑器侧栏**仍保留 taskApi 引用**，等于"开权限缺口让外人也能用 taskApi"，并未减轻核心负担 |
| 结论 | 🟡 投入产出比差 |

### 🅲️ 扩展点插件化 — ✅ **推荐**

| 项目 | 说明 |
|---|---|
| 做什么 | 核心**完全保留**在 Rust + 核心 React；开放扩展点让插件**增强**而非替代 |
| 工作量 | 🟢 小（~1 天） |
| 删除核心代码 | **0 行** |
| 收益 | 用户能装"番茄钟/GTD/日历同步/AI 周报/自定义视图"等增强插件 |
| 风险 | 极低（核心一行不动） |
| 结论 | ✅ **强烈推荐** |

### 🅳️ 长期愿景：AI Plan 内置插件标杆

承认任务核心不该拔，但把 `PlanFromGoalModal` / `PlanTodayModal` 重构为**官方内置插件**作为给第三方插件的示范。
- 现状：AI 直接调 `taskApi.create`
- 改造后：AI 走 `app.tasks.create` 完整插件 API 链路
- `bundled: true` 标记，用户不能禁用
- 工作量：额外 ~1 天，需在 🅲 完成后做

### 4.2 后端 Rust 设计

#### 新增 6 个代理 Command

文件位置：`src-tauri/src/commands/plugin_proxy.rs`（已存在，追加）

```rust
// ─── plugin_proxy_tasks_list ─────────────────────────────
#[tauri::command]
pub async fn plugin_proxy_tasks_list(
    state: tauri::State<'_, AppState>,
    plugin_id: String,
    token: String,
    filter: Option<PluginTaskFilter>,
) -> Result<Vec<PluginTaskView>, String> {
    // 1. 验证插件令牌 + 权限 tasks.read
    PluginAuth::check(&state, &plugin_id, &token, "tasks.read")?;
    // 2. 调 Service 层
    TasksService::list_for_plugin(&state.db, filter.unwrap_or_default())
        .map_err(|e| e.to_string())
}

// - plugin_proxy_tasks_get        (tasks.read)
// - plugin_proxy_tasks_create     (tasks.write + 速率限制)
// - plugin_proxy_tasks_update     (tasks.write + 速率限制)
// - plugin_proxy_tasks_complete   (tasks.write + 速率限制)
// - plugin_proxy_tasks_delete     (tasks.write + 速率限制)
```

#### Service 层补丁

文件位置：`src-tauri/src/services/tasks.rs`（追加方法 + 在关键路径 emit 事件）

```rust
impl TasksService {
    // 新增插件专用方法：脱敏返回 PluginTaskView（不含 source_batch_id 等内部字段）
    pub fn list_for_plugin(
        db: &Database,
        filter: PluginTaskFilter,
    ) -> Result<Vec<PluginTaskView>, AppError> {
        db.list_tasks_for_plugin(filter)
            .map(|tasks| tasks.into_iter().map(Into::into).collect())
    }

    // 在 create / update / complete / delete 关键路径 emit 事件
    pub fn create(
        app: &AppHandle,
        db: &Database,
        input: CreateTaskInput,
    ) -> Result<Task, AppError> {
        let task = db.insert_task(input)?;
        // 🆕 emit 事件给插件总线
        let _ = app.emit("plugin:task:created", &task);
        Ok(task)
    }
    // update / complete / delete 同理
}
```

#### 速率限制

为防止插件爆库，写操作必须经过 `PluginRateLimiter`：

```rust
// src-tauri/src/services/plugin_rate_limit.rs（新建或扩展现有）
pub struct PluginRateLimiter {
    inner: Mutex<HashMap<String, RateLimitState>>,
}

impl PluginRateLimiter {
    /// 每个插件每秒最多 10 次写操作
    pub fn check_write(&self, plugin_id: &str) -> Result<(), AppError> {
        let mut map = self.inner.lock().map_err(|e| AppError::Custom(e.to_string()))?;
        let state = map.entry(plugin_id.to_string()).or_default();
        if state.window_start.elapsed().as_secs() >= 1 {
            state.window_start = Instant::now();
            state.count = 0;
        }
        if state.count >= 10 {
            return Err(AppError::Custom("插件写入速率超限（每秒最多 10 次）".into()));
        }
        state.count += 1;
        Ok(())
    }
}
```

### 4.3 前端 PluginAppAPI 实现

文件位置：`src/services/pluginApi.ts`（追加子模块）

```typescript
// ─── app.tasks.* 子模块 ─────────────────────
function createTasksApi(pluginId: string, token: string): PluginTasksAPI {
  return {
    list: (filter) => {
      preCheck(pluginId, 'tasks.read');
      return invoke<PluginTaskView[]>('plugin_proxy_tasks_list', {
        pluginId, token, filter,
      }).catch((e) => { throw new Error(translateError(String(e))); });
    },
    get: (id) => invoke<PluginTaskView | null>('plugin_proxy_tasks_get', {
      pluginId, token, id,
    }),
    create: (input) => invoke<PluginTaskView>('plugin_proxy_tasks_create', {
      pluginId, token, input,
    }),
    update: (id, patch) => invoke<void>('plugin_proxy_tasks_update', {
      pluginId, token, id, patch,
    }),
    complete: (id) => invoke<void>('plugin_proxy_tasks_complete', {
      pluginId, token, id,
    }),
    delete: (id) => invoke<void>('plugin_proxy_tasks_delete', {
      pluginId, token, id,
    }),
  };
}

// ─── app.taskViews.register ─────────────────
function createTaskViewsApi(pluginId: string): PluginTaskViewsAPI {
  return {
    register(def) {
      // 注册到 PluginManager 的 taskViews 注册表
      PluginManager.registerTaskView(pluginId, def);
      return () => PluginManager.unregisterTaskView(pluginId, def.id);
    },
  };
}
```

```typescript
// src/hooks/usePluginTaskViews.ts（新建）
export function usePluginTaskViews(): ViewDef[] {
  const [views, setViews] = useState<ViewDef[]>([]);
  useEffect(() => {
    const update = () => setViews(PluginManager.getAllTaskViews());

    return PluginManager.onTaskViewsChange(update);
```

## 五、权限矩阵

| 权限 ID | 用途 | 默认状态 | 提示信息 |
|---|---|---|---|
| `tasks.read` | 调用 `app.tasks.list/get` 读取任务列表 | 需用户授权 | "插件 X 想读取你的任务列表" |
| `tasks.write` | 调用 `app.tasks.create/update/complete/delete` | 需用户授权 + 速率限制 | "插件 X 想创建/修改你的任务（每秒最多 10 次）" |
| `tasks.subscribe` | 订阅 `task:*` 事件 | 需用户授权 | "插件 X 想监听任务变化事件" |
| `taskViews.register` | 注册自定义视图 | 需用户授权 | "插件 X 想为任务页面添加 N 个自定义视图" |

权限声明在插件 `manifest.json`：

```json
{
  "id": "io.example.pomodoro",
  "name": "番茄钟",
  "permissions": ["tasks.read", "tasks.subscribe", "tasks.write"]
}
```

## 六、防爆库与安全策略

| 风险 | 缓解方案 |
|---|---|
| 插件批量写入爆库 | `PluginRateLimiter` — 每秒最多 10 次写操作 |
| 插件读取后泄漏到外部 | 配合 `network` 权限分级（已有插件框架支持） |
| 插件视图渲染恶意 JS | iframe 沙箱（沿用现有方案，不允许 top.* 访问） |
| 事件 payload 含内部字段 | `PluginTaskView` 脱敏（去掉 `source_batch_id` / `reminded_at` 等） |
| 插件注册无限多视图 | 单插件最多 5 个视图 |
| AI 批量创建被插件 hook 后篡改 | AI Plan 走原生 `taskApi.create`，**不**走 `app.tasks.create`（阶段 🅳 才迁移） |

### 番茄钟插件 `dev-plugins/pomodoro/main.js`

```javascript
export async function activate(ctx) {
  const { app } = ctx;
  let activeTimer = null;

  // 监听任务创建，主动询问
  const off = app.events.on('task:created', async (task) => {
    const result = await app.dialog.confirm({
      title: '开始番茄钟？',
      message: `任务"${task.title}"已创建，是否立即开始 25 分钟专注？`,
    });
    if (result) startPomodoro(task);
  });

  function startPomodoro(task) {
    if (activeTimer) clearTimeout(activeTimer);
    app.notifications.show({ title: '🍅 番茄钟开始', body: task.title });
    activeTimer = setTimeout(async () => {
      app.notifications.show({ title: '✅ 完成 1 个番茄', body: task.title });
      await app.tasks.update(task.id, {
        description: (task.description || '') + `\n🍅 ${new Date().toLocaleString()}`,
      });
      activeTimer = null;
    }, 25 * 60 * 1000);
  }

  return { deactivate: () => { off(); if (activeTimer) clearTimeout(activeTimer); } };
}
```
